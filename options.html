Private, local settings for your visual lecture workflow.

Connection
Stored locally

Create a key in the Sarvam dashboard. WiseNotes uses Chat Completions, Document AI, and Text Translation. API usage consumes Sarvam credits.

Visual intelligence
◫

Sarvam-105B plans visual moments from captions. Sarvam Vision reads selected frames through Document AI OCR. OCR can recover text, equations, code, and tables, but can miss faint handwriting and diagram geometry.

Language
Notes in English

Indic captions and OCR prose are translated into English. If the board uses a different language from the captions, select it here to improve OCR. Equations and code stay unchanged.

⌁
Privacy boundary

Captions and OCR text may go to Sarvam for language detection and English translation. The English transcript goes to Sarvam-105B for visual planning. Selected cropped JPEGs go to Document AI for OCR. WiseNotes saves original evidence and translation progress locally for Resume. Sarvam may retain uploads under its service terms. The universal prompt is built locally; you choose where to paste it.
